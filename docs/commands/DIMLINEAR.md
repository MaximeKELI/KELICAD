# DIMLINEAR (DLI)

Create a linear dimension between two extension points.

## Prompts

1. First extension point  
2. Second extension point  
3. Dimension line location  

## Notes

Measured length is computed by the core (`DimensionGeom::measured_length`). Associativity fields are reserved (`assoc_a` / `assoc_b`) for follow-up grips linkage.
